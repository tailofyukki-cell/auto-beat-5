Combo cut-in images

Put milestone-specific images in this folder to change the gameplay cut-in shown at 50-combo intervals.

Supported image extensions: png, jpg, jpeg, webp, gif.

Naming examples:
  combo_50.png
  combo_100.png
  combo_150.png

Short names are also supported:
  50.png
  100.png

Fallback:
  default.png

If no matching image and no default image are found, AutoBeat 5 uses the currently selected mascot image, matching the original behavior. For video-like cut-ins, export the clip as a few still images and choose one per milestone for now.
