# AutoBeat 5 実装監査（更新版）

**更新日:** 2026-08-18  
**対象版:** 1.1相当のソースコード

| 領域 | 状況 | 実装内容 |
|---|---|---|
| 5レーン・キーコンフィグ | 実装済み | D / F / Space / J / Kを初期値とし、重複しない任意キーへ再割当できる。 |
| 音源読込 | 実装済み | MP3 / WAV / OGG / FLACの選択、解析エラーの表示、ローカルキャッシュを実装。 |
| 楽曲ライブラリー | 実装済み | 解析済み音源のパス、ハッシュ、BPM、曲長を最大20件まで保存し、選曲画面から再利用できる。音源本体はコピーしない。 |
| 音楽解析 | 実装済み | BPM、beat、局所BPM、小節頭候補、onset、HPSSによる打楽器・持続音分離、帯域エネルギー、持続候補を抽出する。 |
| 自動譜面 | 実装済み | 低域をD/F、高域をJ/K、強いリズムと小節頭をSpaceへ優先配置。5難易度、同時押し、長押し、連打的な交互パターンを生成する。 |
| プレイ可能性 | 実装済み | 同一レーン間隔、同時押し数、片手負荷、同一手の重なる長押しを検査・補正する。長押し開始位置の重複tapも除去する。 |
| 判定・スコア | 実装済み | PERFECT / GREAT / GOOD / MISS、Timing Offset、コンボ、スコア、精度、ランクを実装。長押しはSTART / HOLD / RELEASEを内部評価し、リザルトはノーツ単位で集計する。 |
| 演出・一時停止 | 実装済み | 50 / 100 / 500 COMBOのバナー、判定音、再開・リトライ・選曲へ戻る一時停止メニューを実装。 |
| 設定 | 実装済み | 音楽・効果音音量、ノーツ速度、Timing Offset、3段階の判定幅、フルスクリーン、解像度、キーコンフィグを保存・変更できる。 |
| 画像解放 | 実装済み | 累積スコア、外部`rewards/`、JSON条件、解放演出、永続化を実装。 |
| ギャラリー | 実装済み | 解放済みサムネイル、未解放の鍵表示、ページ送り、クリック後の拡大表示、解放条件表示を実装。 |
| 配布準備 | 実装済み | PyInstaller設定、Windowsビルドバッチ、ライセンス通知、README、受入・公開チェックリストを用意。 |

## 今回完了した補強項目

初回実装後に見つかった不足は、すべてソースコード上で補強した。特に、ギャラリーは一覧だけでなく拡大表示まで対応し、画像追加・差替え・解放条件変更を外部フォルダで完結できる。設定画面は、保存するだけだった効果音音量、フルスクリーン、解像度、PERFECT / GREAT / GOODの判定幅を実際に操作・反映できるようにした。

譜面生成では、打楽器成分と持続音をHPSSで分離し、小節頭候補と局所BPMを保存する構造へ更新した。生成後の長押しでは、同じ開始時刻・レーンに通常ノーツが重なる問題を解消している。また、連続onsetを難易度に応じた左右交互またはSpaceを含むパターンに再配置する処理を追加した。

## 実機でのみ最終判定すべき項目

| 項目 | 理由 | 実施内容 |
|---|---|---|
| Windows実行ファイル | この開発環境はLinuxであり、最終成果物はWindowsネイティブの`.exe`で検証する必要がある。 | Windows上で`build_windows.bat`を実行し、生成された`dist\AutoBeat5\`を別PCでも起動する。 |
| 音ズレ | 音声デバイス、ドライバ、出力方式、入力遅延はPCごとに異なる。 | 複数PC・ヘッドホン・スピーカー環境でTiming Offsetを調整し、体感同期を確認する。 |
| 譜面の音楽性 | 自動テストでは安全性・決定性を確認できても、演奏感は人間の評価を要する。 | ドラム、ベース、メロディ、静音、BPM変化、高BPMを含む実音源で手動プレイテストを行う。 |
| 形式別デコード | Pygame/SDLのデコーダー対応は配布先のWindowsビルドで最終確認が必要。 | MP3 / WAV / OGG / FLACを実機で各1曲以上解析・再生する。 |

> 実装対象の機能は完了し、残る作業は主にWindows実機での品質保証と、実音源に対する譜面の手動チューニングである。
