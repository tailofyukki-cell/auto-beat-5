## 詳細確認

### プレイ感と譜面

| ID | 確認項目 | 合格の目安 | 結果・メモ |
|---|---|---|---|
| P-01 | BEGINNER / EASY / NORMAL以上を遊ぶ | 難易度が上がるほど密度や操作量が自然に増える | |
| P-02 | EASYの長押しを確認する | 長押しが少なすぎず多すぎず、曲の持続音に合っている | |
| P-03 | 長押ししながら別レーンを連打する | 誤って必ずNGになることがなく、押下・終端判定も自然 | |
| P-04 | 静かな曲、速い曲、低音中心の曲を各1曲遊ぶ | 極端な無譜面、過密、単一レーン偏重が起きない | |
| P-05 | 譜面候補を最大5つ作り直す | 候補ごとの差が分かり、以前の確定譜面を誤って失わない | |
| P-06 | Timing Offsetを調整する | 見た目と耳のタイミングが一致する値を保存できる | |

## 不具合を見つけたときの記録

次の情報があると修正が速くなります。

- 上表のID
- 直前からの操作手順
- 期待した表示・動作と実際の表示・動作
- 何回中何回発生したか
- 使用した曲の形式、長さ、BPMの傾向
- 画面解像度と選択レーン数
- スクリーンショット。ちらつきや同期ずれは可能なら短い動画
- フリーズ時は、音が続いていたか、入力だけ止まったか、画面全体が止まったか

## 今回の合否判断

- 必須15分コースにNGが1件でもあれば、リリースZIP更新前に修正する。
- 詳細確認のNGは、再現頻度とプレイへの影響を添えて優先度を決める。
- 「譜面が音楽を叩いている感覚」は数値だけで決めず、曲ごとの感想を1行残す。
