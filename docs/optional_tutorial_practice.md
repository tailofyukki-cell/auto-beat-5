# 任意チュートリアル練習

2026-10-02追加。既存の基本5課題は維持し、一覧から直接選べる任意練習を3つ追加。
チュートリアル未完了でも選択可能。現在選択中の3・5・7レーンに対応。
音源不要、120 BPMの既存メトロノームと通常の判定処理を使用。

## 長押し前後の密集

- 19秒、HOLD4本とTAP32個。
- 左右交互に1.5秒のHOLDを配置。
- 開始・終了それぞれの0.5秒前、0.25秒前、0.25秒後、0.5秒後にTAP。
- HOLD中は反対側と中央のレーンを使い、保持しているキーへの再入力は要求しない。

## 連続同時押し

- 0.5秒間隔の2個同時押し。
- 左右の外側、内側、中央との組み合わせ、5・7レーンでは同じ側のペアも使用。
- 6パターン（3レーン）または8パターン（5・7レーン）の配列を3周。
- 3レーンでは一部の組み合わせが重複。3レーンは36ノーツ・12.5秒、5・7レーンは48ノーツ・15.5秒。

## 単発ノーツの密集

- 19.75秒、TAP64個。同時押し・HOLDなし。
- 120 BPMの半拍にあたる0.25秒間隔で配置。
- 左右交互、階段状の往復、中央を挟む交互、同じレーンの2連打を各16ノーツ。
- 3・5・7レーンそれぞれの配置に対応し、階段パターンで全レーンを使用。

## 終了と再挑戦

- 完走後に専用のチュートリアル結果画面へ。ENTERまたはRで同じ課題を再挑戦。
- ESCで課題一覧へ戻る。プレイ中のESCによる一時停止・再開も既存の操作を維持。
- 自動ループではなく、結果を確認してから手動で繰り返す。
- 任意練習は基本課題の進行に含めず、チュートリアル完了フラグ・解放・BP・ランキングを変更しない。
- 基本5課題の最終課題による既存の完了・解放処理は維持。

## 検証

- 3・5・7レーンの全3課題についてKEYDOWN/KEYUPで全ノーツPERFECTを確認。
- 任意練習終了前後のプロフィール不変、ENTER再挑戦、一覧復帰をテスト。
- 一覧の各ボタンの画面内配置・非重複をテストし、960×540の画像で表示確認。
