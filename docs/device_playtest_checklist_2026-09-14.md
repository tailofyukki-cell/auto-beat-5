## 1. 起動・配布物

- [ ] 展開先フォルダ名が `Otoasobi` になっている。
- [ ] `Otoasobi.exe` と `Otoasobi_User_Guide.pdf` が入っている。
- [ ] `RC1_TEST_CHECKLIST.md` と `RELEASE_CHANNEL.txt` が入っていない。
- [ ] EXEを起動でき、操作説明PDFも開ける。
- [ ] 以前のスコア・購入内容・設定が引き継がれている。
- [ ] 最初の画面の終了ボタンから正常に終了できる。

## 2. タイトル・曲選択

- [ ] タイトルの演出が表示され、マスコットをクリックすると反応する。
- [ ] 各メニューボタンを選択できる。
- [ ] 曲選択の装飾で曲名や選択状態が見づらくなっていない。
- [ ] キーボード・マウスで選曲でき、スクロールも正常に動く。
- [ ] 曲名・背景画像・ご褒美画像などの表示名に拡張子が付いていない。
- [ ] 長い名前が隣の情報やボタンに重ならない。
- [ ] フォルダ作成と曲の移動ができる。
- [ ] 再起動後、最後に開いたフォルダから曲選択を始められる。

## 3. 読み込み・譜面生成

- [ ] 同梱曲と自分の曲を読み込める。
- [ ] 日本語のファイル名・フォルダ名でも読み込める。
- [ ] 手元にある MP3 / WAV / OGG / FLAC を読み込める（ない形式は未確認と記録）。
- [ ] 譜面生成・再生成・候補の比較と採用ができる。
- [ ] お試しプレイが最大1分でフェードアウトして終了する。
- [ ] 1分未満の曲はお試しプレイで最後まで再生される。
- [ ] お試しプレイ・練習では通常のスコア記録やBPが増えない。

## 4. プレイ【優先】

- [ ] 同じ曲・難易度で通常表示と3D表示を試し、判定タイミングに違和感がない。
- [ ] 3Dノーツが判定直前に急に加減速したり、跳ねたりしない。
- [ ] 長押し中に別レーンの通常ノーツを正常に叩ける。
- [ ] 長押しの線・発光が同じレーン内に収まっている。
- [ ] 同時押しをつなぐ細い線が見え、少しずれたノーツと区別できる。
- [ ] 左下のESC案内が表示され、プレイを邪魔しない。
- [ ] マスコット・コンボ演出・スコア表示中に気になる引っかかりがない。
- [ ] 背景画像・ビジュアライザーを使ってもノーツを見分けられる。

## 5. カーソル・一時停止【最優先】

- [ ] プレイ開始時はマウスカーソルが非表示になる。
- [ ] マウスを動かすと表示され、動かさず約2秒待つと消える。
- [ ] 一時停止するとカーソルが表示される。
- [ ] 再開するとカーソルが消え、すべてのレーンキーが効く。
- [ ] 一時停止と再開を5回以上繰り返しても入力不能にならない。
- [ ] 長押し中に一時停止しても、再開後にキーが押しっぱなし扱いで残らない。
- [ ] Alt+Tabで別ウィンドウに移って戻っても、再開後に入力できる。
- [ ] 結果・設定・曲選択・タイトルではカーソルが表示される。
- [ ] 練習・お試しプレイでもカーソルと一時停止の動作が正常。

## 6. 結果・設定・購入

- [ ] 曲終了後、コマンドプロンプトの点滅やフリーズが起きない。
- [ ] リトライ・難易度変更・曲選択への移動ができる。
- [ ] 曲選択ボタンの右に設定ボタンがあり、設定画面を開ける。
- [ ] リザルト画像を保存できる。
- [ ] キャラクターのセリフ・スコア・ボタンが重ならない。
- [ ] 効果音の種類を左右で変更すると試聴できる。
- [ ] マスコット・ノーツ・背景などの設定とプレビューが正常。
- [ ] 設定を保存して再起動しても選択内容が残る。
- [ ] 未購入アイテムの購入確認・BP消費・解放が正常。
- [ ] 購入済みアイテムで二重にBPが減らず、再起動後も所有状態が残る。

## 7. 小さい画面【優先】

- [ ] ノートPCの小さい解像度で各画面の文字・ボタンが収まる。
- [ ] 設定項目・プレビュー・保存ボタンが重ならない。
- [ ] クリックした位置と反応するボタンの位置が一致する。
- [ ] 通常表示で1曲最後まで遊べる。
- [ ] 3D表示で1曲最後まで遊べる。
- [ ] 利用可能な3・5・7レーンで表示のはみ出しがない。
- [ ] ウィンドウ・フルスクリーンを切り替えても表示と操作が正常。
