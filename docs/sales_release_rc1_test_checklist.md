# AutoBeat 5 Sales Release Candidate 1 — Windows Test Checklist

この手順は、販売候補ZIPを**開発フォルダとは別の新しい空フォルダ**へ展開して実行します。文字化けした旧ファイルが残らないよう、古い展開先へ上書きしないでください。

## 0. テスト対象の確認

| 項目 | 記録欄 |
|---|---|
| ZIPファイル名 | |
| ZIP SHA-256 | |
| テスト日時 | |
| Windowsのバージョン | |
| テストPC（開発用ではないPCならその旨） | |
| テスター名または識別子 | |

ZIPのSHA-256がリリースノート記載値と一致することを確認してください。WindowsのエクスプローラーでZIPを展開し、展開先の `AutoBeat5\AutoBeat5.exe` を起動します。

## 1. 配布物の健全性

| ID | 手順 | 合格基準 | 結果 |
|---|---|---|---|
| P-01 | ZIPを新しい空フォルダへ展開する | エラーなく展開できる | |
| P-02 | `demo_songs` を開く | `ここから始まる～夜明けの光～.wav` が文字化けせず表示される | |
| P-03 | `licenses\INDEX.md` を開く | ライセンス一覧とSBOMが読める | |
| P-04 | `AutoBeat5.exe` を起動する | 5秒以内にタイトル画面が表示される | |
| P-05 | 一度終了して再起動する | 設定・プロフィールの破損エラーがない | |

## 2. 遊べることの確認

| ID | 手順 | 合格基準 | 結果 |
|---|---|---|---|
| G-01 | `PLAY` → `DEMO SONGS` を開く | デモ3曲の曲名が正しく表示される | |
| G-02 | 各デモ曲を選び、BEGINNERを開始する | 再解析待ちなしで譜面選択・3秒カウントダウンへ進む | |
| G-03 | ノーツを数回叩く | PERFECT/GREAT/GOOD/MISSが短時間で消え、画面に残り続けない | |
| G-04 | 曲を最後まで1曲プレイする | 終端の音が極端に途切れず、リザルトへ移行する | |
| G-05 | `TUTORIAL` を最後まで進める | 4ステップを完了できる | |
| G-06 | `PLAY` から自分のMP3/WAVを選ぶ | 解析、譜面生成、BEGINNER開始ができる | |
| G-07 | 日本語名・日本語パスのWAVを選ぶ | 文字化け・デコードエラーなく解析できる | |

## 3. 保存と報酬の確認

| ID | 手順 | 合格基準 | 結果 |
|---|---|---|---|
| S-01 | プレイ後にRESULTを見る | スコア、コンボ、次の画像までの進捗が表示される | |
| S-02 | `GALLERY` を開く | 解放済み/未解放、必要スコア、残りスコアが表示される | |
| S-03 | GALLERYで`M`を押す | REWARD MANAGERが開き、報酬一覧をスクロールできる | |
| S-04 | `L`を押して楽曲ライブラリーを開く | 過去に解析した曲をスクロールし、選び直せる | |
| S-05 | 終了後に再起動する | 楽曲ライブラリー、自己ベスト、累積スコアが保持される | |
