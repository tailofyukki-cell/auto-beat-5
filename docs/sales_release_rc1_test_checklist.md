# AutoBeat 5 Sales Release Candidate 1 — Windows Test Checklist

この手順は、販売候補ZIPを**開発フォルダとは別の新しい空フォルダ**へ展開して実行します。文字化けした旧ファイルが残らないよう、古い展開先へ上書きしないでください。

## 0. テスト対象の確認

| 項目 | 記録欄 |
|---|---|
| ZIPファイル名 | |
| ZIP SHA-256 | |
| テスト日時 | |
| Windowsのバージョン | |
| テストPC（開発用ではないPCならその旨） | |
| テスター名または識別子 | |

ZIPのSHA-256がリリースノート記載値と一致することを確認してください。WindowsのエクスプローラーでZIPを展開し、展開先の `AutoBeat5\AutoBeat5.exe` を起動します。

## 1. 配布物の健全性

| ID | 手順 | 合格基準 | 結果 |
|---|---|---|---|
| P-01 | ZIPを新しい空フォルダへ展開する | エラーなく展開できる | |
| P-02 | `demo_songs` を開く | `ここから始まる～夜明けの光～.wav` が文字化けせず表示される | |
| P-03 | `licenses\INDEX.md` を開く | ライセンス一覧とSBOMが読める | |
| P-04 | `AutoBeat5.exe` を起動する | 5秒以内にタイトル画面が表示される | |
| P-05 | 一度終了して再起動する | 設定・プロフィールの破損エラーがない | |

## 2. 遊べることの確認

| ID | 手順 | 合格基準 | 結果 |
|---|---|---|---|
| G-01 | `PLAY MUSIC` を開く | デモ3曲が**PLAYLIST**内に正しい曲名で表示される | |
| G-02 | 各デモ曲を選び、BEGINNERを開始する | 再解析待ちなしで譜面選択・3秒カウントダウンへ進む | |
| G-03 | ノーツを数回叩く | PERFECT/GREAT/GOOD/MISSが短時間で消え、画面に残り続けない | |
| G-04 | 曲を最後まで1曲プレイする | 終端の音が極端に途切れず、リザルトへ移行する | |
| G-05 | `TUTORIAL` を最後まで進める | 4ステップを完了できる | |
| G-06 | `PLAY MUSIC`から自分のMP3/WAVを選ぶ | 解析、譜面生成、BEGINNER開始ができる | |
| G-07 | 解析後にPLAYLISTへ戻る | デモ曲と自分の曲が同じ一覧にあり、マウスホイール・↑↓・PageUp/PageDownで選べる | |
| G-08 | 同じデモ音源を別パスから解析した後にPLAYLISTを開く | 同一SHA-256の曲は一行に統合され、手元の音源が優先される | |
| G-09 | 日本語名・日本語パスのPCM WAVを選び、PRACTICEで開始位置を0以外に設定する | 文字化け・デコードエラーなく解析でき、指定位置から練習を開始できる | |
| G-10 | `PRACTICE`→曲→難易度→区間設定でループONを選ぶ | 区間末尾で指定開始位置へ戻り、譜面・音源が同期して繰り返される | |
| G-11 | ループOFFで練習を終える | 練習結果が表示され、通常ランキング・累積スコア・画像解放が増えない | |
| G-12 | SETTINGSでマスコット演出をSTANDARDにして通常プレイを開始する | マスコットがノーツレーン外の横余白でビートに合わせて動き、譜面・判定線・スコアを隠さない | |
| G-13 | SETTINGSでマスコット演出をOFFにして通常プレイを開始する | マスコットが表示されず、設定保存・再起動後もOFFが維持される | |

## 3. 保存と報酬の確認

| ID | 手順 | 合格基準 | 結果 |
|---|---|---|---|
| S-01 | プレイ後にRESULTを見る | スコア、コンボ、次の画像までの進捗が表示される | |
| S-02 | `GALLERY` を開く | 解放済み/未解放、必要スコア、残りスコアが表示される | |
| S-03 | GALLERYで`M`を押す | REWARD MANAGERが開き、報酬一覧をスクロールできる | |
| S-04 | `PLAY MUSIC`または`PRACTICE`のPLAYLISTを開く | 過去に解析した曲をデモ曲と同じ一覧でスクロールし、選び直せる | |
| S-05 | 終了後に再起動する | PLAYLIST、自己ベスト、累積スコアが保持される | |
| S-06 | 練習を複数回終了後に通常プレイを完了する | 練習の点数は累積・ランキングへ混入せず、通常プレイ分だけが保存される | |
