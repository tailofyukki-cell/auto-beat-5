# リザルトの自己ベスト比較と次の目標

通常プレイのリザルトに表示。練習・お試し・チュートリアルの記録ルールは変更しない。

- 比較対象は同じ曲・難易度・レーン数の過去最高スコアのプレイ。今回を保存する前の記録を保持する。
- スコア差、精度差（パーセントポイント）、MISS数差を表示。MISSのマイナスは改善。
- 精度単独の最高記録や直前のプレイとの比較ではない。譜面候補間の扱いは既存ランキングと同じ。
- 初回は初回記録と表示。古いデータでMISSが不明なら記録なしと表示し、0と仮定しない。
- 次ランクの精度境界はC:70、B:80、A:90、S:95、S+:98かつMISS 0。
- S+達成後はALL PERFECTを目標にし、それも達成したら別難易度への挑戦を案内。
- 実在する未購入コンテンツのうち最安の商品を選び、所持BPとの差を表示。足りていれば「ショップで購入可能」。自動購入・自動解放はしない。
- 新たな比較値は既存プロフィールに追加保存し、古い5レーンの記録も引き継ぐ。

確認: 初回、更新、更新なし、同点、過去MISS不明、難易度・レーンの分離、S+条件、購入可能・全所有、960x540での表示。
