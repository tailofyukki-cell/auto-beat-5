# マスコットのコンボ別ポーズ案

記録日: 2026-09-17

会話で提案した内容の保存用メモ。閾値・切り替え演出は設計案であり、このメモの作成ではゲーム実装や画像追加は行っていない。

## 目標

- マスコットのバリエーションを10キャラまで増やす。
- コンボが続くほど、選択中のマスコットもテンションが上がって見える画像へ切り替える。
- 全年齢向け音ゲーとして、一緒に演奏しているような楽しさを加える。

## コンボとポーズの対応案

| コンボ | 状態 | 表情・ポーズの例 |
|---|---|---|
| 0～49 | 通常 | 落ち着いて応援 |
| 50～99 | ノリノリ | 笑顔、小さく手を上げる |
| 100～199 | 大興奮 | 大きな笑顔、躍動感のあるポーズ |
| 200以上 | 最高潮 | 全力で応援する特別ポーズ |

## 表示・軽量化の方針案

- 画像間で位置と顔の大きさをそろえ、短いクロスフェードで切り替える。
- 必要な画像はプレイ開始前に読み込み、プレイ中のファイル読み込みを避ける。
- ミスした瞬間に通常へ戻さず、少し余韻を残して戻す。時間や戻り方は実装時に調整する。
- 未用意の段階は直前の段階の画像で代用する。
- 50刻みのカットインは瞬間的なお祝い、常駐マスコットは継続的な盛り上がりとして役割を分ける。
- 低負荷PCでも遊べることを重視し、画像のメモリ使用量と切り替え時の負荷を検証する。

## 画像制作の進め方の案

1. 初期キャラのRHYTHMだけ4段階を用意して試す。
2. 視認性・切り替え・負荷を確認してから他のキャラへ広げる。
3. 10キャラすべてに4段階をそろえる場合は合計40枚となるが、最初から全枚数を必須にしない。

会話時点で把握しているキャラは9種類（rhythm、cute、sexy2、cool、powerful、sexy、pixy、neon、DJ）。実際の素材一覧は追加作業時に再確認する。
10体目は、既存キャラとシルエットや色が異なる方向を検討する。具体的なキャラと画像は未決定。
