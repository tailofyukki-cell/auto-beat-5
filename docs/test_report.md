## Windows実機で必須となる受入テスト

サンドボックスではWindowsの音声デバイス、入力遅延、GPU、実際のMP3/OGG/FLACデコーダー差異を完全に再現できません。Windowsビルド後は、次の項目を実機で確認してください。

| 観点 | 受入条件 |
|---|---|
| 起動 | Python未導入のWindows 10 / 11で`AutoBeat5.exe`が起動する。 |
| 形式 | MP3、WAV、OGG、FLACを1曲以上ずつ選択・解析・再生できる。 |
| 同期 | 60 BPM、120〜140 BPM、180 BPM以上、BPMが変化する曲でTiming Offsetを調整し、体感上のズレを確認する。 |
| 譜面品質 | ドラム中心、低音中心、高音中心、静かな曲、音圧の高い曲でレーン割当と難易度差を手動評価する。 |
| 入力 | 初期キーと変更後のキーが重複なく認識される。長押し中に別手で演奏する配置も確認する。 |
| 保存 | 再起動後も設定、ライブラリー、ハイスコア、累積スコア、画像解放、解析・譜面キャッシュが残る。 |
| 配布 | `dist/AutoBeat5/`フォルダ全体を別PCへコピーして起動できる。 |
| ライセンス | 最終バイナリに含まれるライブラリと`licenses/`を照合する。 |

> 自動テストはプログラム上の退行を検知しますが、「音楽を叩いているように感じるか」という最重要品質はジャンル別の実音源と人間のプレイで評価する必要があります。

## コンボ節目再発火と入力タイミング測定（2026-08-19）

コンボ節目の演出は、過去の到達履歴を保持する方式から、現在の連続コンボ数が50、100、500に**到達した瞬間**を検出する方式へ更新した。したがってMISSでコンボが0へ戻った後、再び50、100、500に到達すると、それぞれのバナーが再表示される。連打時も同じコンボ数では再発火しない。

設定画面に「入力タイミング測定」を追加した。クリック音に合わせてSPACEを押すと、最初の2回をウォームアップとして除外した後、10回の入力偏差を収集する。外れ値の影響を抑えるため中央値を推奨Timing Offsetとして表示し、AまたはENTERで適用・保存できる。Rで測定をやり直し、ESCで保存せず設定へ戻る。入力スケジュール、ウォームアップ、重複入力排除、許容範囲外入力排除、中央値推定、設定画面からの起動、推奨値適用、完了画面の描画を自動テストした。Windows上で全33件の回帰テストに成功し、1280×720のキャリブレーション画面における日本語表示、入力進捗、推奨値、操作案内を視覚確認した。

## 譜面概要・再生成（2026-08-20）

難易度選択後に直ちにゲームを開始するのではなく、譜面概要画面へ進む導線に変更した。概要には、推定BPM、楽曲長、最初の入力時刻、譜面傾向、総ノーツ数、TAP/HOLD内訳、平均・最大ノーツ密度、同時押し回数と最大数、安全補正で除去したノーツ数および注意件数を表示する。

「もう一度生成」は、同一難易度の次の決定論的variantを生成する。ノーツ時刻・音価・中央レーンの強拍アンカーを維持しながら、左右レーン選択を切り替えるため、譜面の難易度傾向を壊さず別候補を提示できる。再生成した譜面は同じ難易度のキャッシュを安全に置換する。ENTERで概要画面からプレイを開始し、Rで再生成、ESCで難易度選択へ戻る。

譜面集計のTAP/HOLD・同時押し・密度・安全補正、概要画面への遷移、プレイ開始が確認操作後になること、variant更新とキャッシュ置換を自動テストした。Windows上で全36件の回帰テストに成功し、1280×720の概要画面における日本語表示、数値表示、再生成・プレイ操作の配置を視覚確認した。

## ローカルランキング・ハイスコア（2026-08-20）
