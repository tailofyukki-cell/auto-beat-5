# 空白バランス v2

## 方針

総ノーツ数を増減させず、密集区間の単独TAPを長い空白内の検出音へ再配置する。
安全性検査後の譜面に適用し、移動のたびに安全性検査をやり直す。
削除が発生する移動は採用しない。判定・入力処理は変更しない。

空白の目安は BEGINNER 2.5秒、EASY 2秒、NORMAL 1.5秒、HARD/EXPERT 1秒。
2026-10-01: v1から各難易度の目安を0.5秒短縮。総数維持と安全性の条件は継続。
HOLD継続中は空白とみなさず、最初のノーツ前と最後のノーツ後は対象外。
検出音がなければ追加しない。弱いノイズの検出まで完全に排除する音声分類ではない。

移動元は前後0.5秒未満に自身を含め4ノーツ以上ある単独のonset TAP。
同時押し、HOLD、downbeat、roll、既に再配置したノーツは移動しない。
削除後に目安以上の空白ができる移動元も除外。弱いノーツから検討する。
移動先は空白の中央に近い検出音を優先し、両端から0.4秒以上空ける。
適切な移動元・移動先がなければ空白を維持する。

## 今後の検討課題: 空白率の目標上限（保留）

2026-10-02: 現行v2を維持し、以下は未実装の検討事項として残す。

- 難易度別に、プレイ区間内の空白時間の割合へ目標上限を設ける。具体的な割合は未決定。
- 冒頭・曲末の余白は必要なものとして保護する。調整前の最初のノーツから最後のノーツ終了（HOLD終端を含む）までを集計範囲として固定する案。
- 目標を超えた場合、長い空白から優先して密集区間の単独TAPを再配置する。
- 総ノーツ数維持、実際の検出音への配置、安全性、同時押し・HOLD等の保護を優先する。
- 必達の上限ではなく努力目標とする。安全な移動元・移動先がなければ目標未達でも終了し、音と無関係な配置やノーツ増加で強制達成しない。
- 評価指標は空白率だけでなく、最長空白と長い空白の回数も併記する。
- 現行の1秒区切り集計は区切る位置に依存するため、指標の定義と境界の扱いを実装前に再検討する。

## 譜面の識別・試し方

既存の確定譜面とスコアは自動更新しない。生成器の既存バージョンも維持。
最新版を起動し、譜面概要の「新しい候補 [R]」を選ぶ。
新規生成・再生成の概要画面には「新方式: 空白バランス v2 / Nノーツ再配置」と表示。
既存v1譜面はそのまま保持し、v1表示を維持する。新しい候補を生成してv2を試す。
0ノーツ再配置も新方式で検査済みという意味。採用するまでは確定譜面を保持する。
再生成時は従来の標準・低音重視・リズム重視の候補切替も行われる。
総数維持は同じ候補の調整前後に対する保証で、別候補間の同数保証ではない。
