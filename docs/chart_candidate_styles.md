# 再生成候補の特徴スタイル

実装日: 2026-09-28

## 使い方

初回生成は従来の標準配置。譜面概要の「新しい候補」で標準・低音重視・リズム重視の候補を生成する。
曲の解析結果で利用可能なスタイルを選び、そのリストを生成variant番号で順に巡回する。
両特徴がある曲では初回標準、再生成は低音重視、リズム重視、標準、低音重視…となる。
直近5候補の比較・試遊・採用・破棄は従来どおり。スタイル名は譜面概要の見出しに表示する。

## 音楽的な条件

- 低音重視: 5音域の合計に対して低い2音域のエネルギーが45%以上の立ち上がりが対象。
- リズム重視: 解析済みの打楽器成分強度が0.35以上の立ち上がりが対象。
- 各条件を満たす立ち上がりが曲全体の20%以上かつ3件以上の場合だけ、そのスタイルを候補に加える。
- 特徴が乏しい、または解析情報が欠ける場合は標準のみ。楽器名の識別・分離を行う機能ではない。

## 配置

- 低音重視は中央の1つ左、リズム重視は中央レーンに対象の通常ノーツを寄せる。
- 3レーンでは低音重視の軸は左端、5・7レーンでは中央の1つ左。
- 最終レーン分散の評価に「特徴レーンからの距離×6」のコストを追加する。
- 従来の直近使用量、全体使用量、移動距離、連打回避も残す。固定配置ではなく緩い優先度であり、長い曲では負担分散も働く。
- 小節頭、ロール、長押しの配置は従来の優先処理を維持する。
- 音の選択、時刻、同時押し・長押し頻度のルールは変更しない。ただし配置後の安全補正によって最終ノーツ数が変わることはある。
- 同一キー間隔、同時押し上限、HOLD衝突、片手への集中は従来のChartValidatorで検査する。

## 互換性と制約

スタイルはmetadataのgeneration_style、generation_style_versionに保存する。古い譜面で項目がない場合は標準として表示。
既存の確定キャッシュを強制再生成しないため、生成器の既存VERSIONは維持し、特徴配置部分の版を別metadataに記録する。
generateのstyle省略時は従来の標準。再生成variantに応じたスタイル選択はアプリの生成経路から明示指定する。
追加の音源解析やモデルは使わない。同じ解析・難易度・レーン数・variant・スタイルなら同じ譜面になる。
異なるスタイルでも曲や安全補正の結果によって配置が似る可能性があり、全候補の一意性は保証しない。
今後の高音重視・フレーズ重視・楽器分離は今回の対象外。

## 確認

合成解析データで、標準に対して特徴レーンからの平均距離が小さくなること、時刻の維持、再現性、3/5/7レーンと全難易度の安全検査をテスト。
候補採用後のスタイル保存と、採用前に確定譜面が変わらないことも確認する。
実曲での楽しさ・集中の強さは今後の実プレイで評価する。配布EXE/ZIPは未再ビルド。
