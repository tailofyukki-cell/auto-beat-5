# AutoBeat 5 公開チェックリスト

## Windowsビルド

| 確認項目 | 完了条件 |
|---|---|
| 依存関係 | Windows上で`build_windows.bat`がエラーなく完了する。 |
| 実行 | `dist\AutoBeat5\AutoBeat5.exe`がPython未導入のWindows 10 / 11で起動する。 |
| 同梱物 | `licenses/`、`docs/`、`rewards/`フォルダが`AutoBeat5.exe`と同じ配布フォルダ内にある。 |
| 可搬性 | `dist\AutoBeat5\`フォルダ全体を別PCへコピーして起動する。 |
| セキュリティ | 販売・継続配布時はコード署名とウイルススキャン結果の案内を検討する。 |

## 機能受入

| 領域 | 完了条件 |
|---|---|
| 音源読込 | MP3、WAV、OGG、FLACを各1曲以上選択・解析・再生できる。 |
| 譜面 | 各難易度が生成され、同じ曲・難易度のキャッシュ再読込で同じ譜面になる。 |
| 演奏 | 通常、同時押し、長押し、連続onsetによる連打的配置を確認する。 |
| 同期 | Timing Offsetを調整し、複数PC・複数音声出力環境で判定の体感を記録する。 |
| 保存 | 再起動後も設定、履歴、ハイスコア、画像解放、キャッシュが維持される。 |
| ご褒美 | 外部`rewards/`に画像と設定を追加し、再ビルドなしでギャラリーへ反映される。 |

## 配布・権利

| 項目 | 完了条件 |
|---|---|
| 音源 | 市販曲などをゲーム配布物に含めない。利用上の注意をストアページ・READMEへ掲載する。 |
| 依存関係 | `licenses/THIRD_PARTY_NOTICES.md`と最終バイナリ内の依存ライブラリを照合する。 |
| フォント・画像 | 同梱する独自素材の利用範囲とクレジット要否を確認する。 |
| ゲーム本体の権利 | ソースコード公開か非公開か、無償か有償かに応じて本体ライセンス・利用規約を決める。 |
| ストア情報 | スクリーンショット、操作方法、対応OS、既知の制限、問い合わせ先を準備する。 |

> 本作の品質基準は、単に動作することではなく、プレイヤーが音源のベース、リズム、持続音、フレーズを手で演奏していると感じられることです。公開候補曲を決め、ジャンル別の手動プレイ評価を必ず実施してください。
