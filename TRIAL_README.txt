AutoBeat 5 Trial Version
=========================

Thank you for playing AutoBeat 5 Trial Version.

How to start
------------
1. Extract the entire ZIP file to any folder.
2. Run AutoBeat5.exe.
3. Select PLAY MUSIC on the title screen.
4. Choose a demo song from PLAYLIST. Demo songs and any music you later analyze are shown in one list.
5. Choose a difficulty and press Enter to play.

Practice mode
-------------
1. Select PRACTICE on the title screen (or press P).
2. Choose a song and difficulty from the same PLAYLIST.
3. Set the start/end positions, then press Enter to begin.
4. Practice scores, rankings, total score, and gallery rewards are never changed by this mode.

Included demo songs
-------------------
- Electric Dreams of Tomorrows.mp3
- Galactic Highway Rushes.mp3
- ここから始まる～夜明けの光～.wav

All included demo songs are provided by the developer for this trial version.
Do not extract, redistribute, upload, or use the audio files separately without permission.

Controls
--------
- D / F / SPACE / J / K: Play notes
- ESC: Pause or resume
- P: Open PRACTICE from the title screen
- PLAYLIST: Up/Down, PageUp/PageDown, Home/End, mouse wheel; I adds music
- Practice setup: Left/Right changes start, A/D changes end, Shift changes by 1 second, L toggles loop
- During practice: L toggles loop, Q returns to practice setup
- T: Open the no-music metronome tutorial from the title screen

Notes
-----
- Keep AutoBeat5.exe, _internal, demo_songs, rewards, docs, and licenses in the same folder.
- The trial package includes prepared analysis data and charts for every demo song. Demo songs open without first-time analysis.
- You may use PLAY MUSIC > 音楽を追加 (or I in PLAYLIST) to play music you own or are authorized to use. Such music is not included in this package.
- A missing user music file is marked MISSING in PLAYLIST. Re-linking a moved file is not yet available.
- Local settings, scores, and analysis caches are stored under %APPDATA%\AutoBeat5.

System requirements
-------------------
- Windows 10 or Windows 11
- Keyboard
- Audio output device
