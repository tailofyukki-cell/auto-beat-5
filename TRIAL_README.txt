AutoBeat 5 Trial Version
=========================

Thank you for playing AutoBeat 5 Trial Version.

How to start
------------
1. Extract the entire ZIP file to any folder.
2. Run AutoBeat5.exe.
3. Select PLAY on the title screen.
4. Choose a song from DEMO SONGS.
5. Choose a difficulty and press Enter to play.

Included demo songs
-------------------
- Electric Dreams of Tomorrows.mp3
- Galactic Highway Rushes.mp3
- ここから始まる～夜明けの光～.wav

All included demo songs are provided by the developer for this trial version.
Do not extract, redistribute, upload, or use the audio files separately without permission.

Controls
--------
- D / F / SPACE / J / K: Play notes
- ESC: Pause or resume
- T: Open the no-music metronome tutorial from the title screen

Notes
-----
- Keep AutoBeat5.exe, _internal, demo_songs, rewards, docs, and licenses in the same folder.
- The trial package includes prepared analysis data and charts for every demo song. Demo songs open without first-time analysis.
- You may use PLAY > 音楽ファイルを選択 to play music you own or are authorized to use. Such music is not included in this package.
- Local settings, scores, and analysis caches are stored under %APPDATA%\AutoBeat5.

System requirements
-------------------
- Windows 10 or Windows 11
- Keyboard
- Audio output device

Feedback
--------
Please report the demo song, difficulty, score, and any issue you found.
