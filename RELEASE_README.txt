オトアソビ
好きな曲を、遊ぼう。
====================

自分の音楽ファイルを読み込み、自動生成された譜面で遊ぶ音楽ゲームです。

起動方法
--------
1. Otoasobi_Windows.zipを新しいフォルダにすべて展開します。
2. Otoasobi.exeを起動します。
3. 初めての方はTUTORIAL、曲を選んで遊ぶ方はPLAY MUSICへ進みます。
4. PLAYLISTの「音楽を追加」またはIキーで、自分の曲を読み込めます。
5. 曲と難易度を選び、譜面概要でEnterを押すとプレイが始まります。

基本操作
--------
- 初期の5レーン：D / F / Space / J / K
- ESC：プレイの一時停止・再開
- SETTINGS：音量、表示、キー設定など。変更後は「設定を保存」。
- PRACTICE：区間を指定して練習。通常の記録やBPには加算されません。
- SHOP：通常プレイで獲得したBPを使ってアイテムを購入。
- GALLERY：解放済みのご褒美画像を表示。
- タイトル画面右下の「終了」でゲームを終了できます。

詳しい操作・解放条件は、同梱のOtoasobi_User_Guide.pdfをご覧ください。

データと更新
------------
旧名称はAutoBeat 5です。既存データとの互換性のため保存先だけは旧名称を使用しています。
EXEだけを移動せず、_internal、assets、demo_songs、rewards、licensesなどを
まとめて保管してください。
この販売用ビルドの設定・スコア・解析キャッシュの標準保存先は
%APPDATA%\AutoBeat5_Release_RC1 です。
更新前には保存データとrewards/unlocked内の解放済み画像をバックアップし、
新しいZIPは別フォルダに展開してください。

音楽の利用について
------------------
読み込む曲は、自分が所有するか適法に利用できるファイルを使用してください。
同梱デモ曲の音源を、許可なく単独で再配布・アップロード・転用しないでください。
第三者ライブラリ等のライセンスはlicensesフォルダをご覧ください。

動作環境と不具合報告
------------------
Windows 10 / 11、キーボード、音声出力機器が必要です。
不具合の報告には、曲名・難易度・レーン数・表示モード・解像度・再現手順を
添えてください。個人の音楽ファイルを無断で共有する必要はありません。
