AutoBeat 5 - Demo Songs
========================

Place demo music created by the developer in this folder.

Supported formats:
- MP3 (.mp3)
- WAV (.wav)
- OGG (.ogg)
- FLAC (.flac)

Behavior:
- Files placed here are shown in the PLAY screen under "DEMO SONGS".
- The game analyzes a demo song and generates its chart in the same way as user-selected music.
- Up to two demo songs are displayed on the song-select screen. Keep the folder focused on the best examples.
- The folder is copied into the Windows distribution when build_windows.bat is run.

Distribution checklist:
1. Use only music you created yourself or have explicit distribution rights for.
2. Keep the file name short and descriptive.
3. Build the game after adding or replacing demo music in the source project.
4. Test every demo song from the released dist\AutoBeat5\demo_songs folder.

This README may remain in the folder. The game ignores non-audio files.
